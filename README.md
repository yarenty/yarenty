### 🐧 The rookery

Three Rust projects that work together: agents, the framework their tools are built on, and spreadsheets they can query.

| Project | What it is | |
|---|---|---|
| [**kowalski**](https://github.com/yarenty/kowalski) | A Rust multi-agent framework: agents with MCP tools and memory, and **hordes** — step pipelines with cron, file-watch and webhook triggers — over Ollama or any OpenAI-compatible model. One binary with the app inside. | [![crates.io](https://img.shields.io/crates/v/kowalski?color=d62828)](https://crates.io/crates/kowalski) [blog](https://kowalski.yarenty.com) |
| [**tableski**](https://github.com/yarenty/tableski) | Every spreadsheet is a table: SQL over Excel, CSV and Parquet via MCP, built on DataFusion. Local binary, or hosted at [tableski.io](https://tableski.io). | [![crates.io](https://img.shields.io/crates/v/tableski?color=0e7490)](https://crates.io/crates/tableski) |
| [**emperor-mcp**](https://github.com/yarenty/emperor-mcp) | An MCP server framework for Rust: Streamable HTTP first, credential forwarding, audited framing. tableski and kowalski's Rookery server are built on it. | [![crates.io](https://img.shields.io/crates/v/emperor-mcp?color=3c5a78)](https://crates.io/crates/emperor-mcp) |
